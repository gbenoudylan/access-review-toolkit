# Versions plafonnées (pas seulement un minimum) : une montée de version
# majeure d'une dépendance peut casser silencieusement l'outil sans que
# personne ne s'en aperçoive avant longtemps — déjà vécu concrètement
# cette année avec un changement de comportement de pandas 3.0 sur la
# conversion .astype(str) des valeurs manquantes. Le plafond n'empêche
# pas de mettre à jour : il force juste à le faire consciemment (relire
# les notes de version, relancer `pytest tests/`) plutôt que sans y
# penser via un simple `pip install -r requirements.txt` qui embarquerait
# une version jamais testée avec cet outil.
# pytesseract nécessite aussi le binaire système 'tesseract-ocr' (pas
# installable via pip) : sur Debian/Ubuntu, `apt install tesseract-ocr` ;
# sur macOS, `brew install tesseract`. Sans ce binaire, la lecture de
# fichiers image (.jpeg/.jpg/.png) échoue avec un message d'erreur clair.
